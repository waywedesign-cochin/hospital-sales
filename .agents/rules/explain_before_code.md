# Explain Before Code

**Description:** Enforces a step-by-step logical explanation before writing code.

**Rules:**
1. When asked to write, modify, or generate code, you MUST first explain the logic and your intended approach step-by-step.
2. Break down the problem into clear, logical steps.
3. Explain the approach for each step clearly.
4. Only provide the code implementation *after* this explanation is complete.
